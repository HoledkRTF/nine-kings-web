# Project Agents & Version History

## Recent Codenames
* **Corner-Knock** (Tag: `Corner-Knock`) — The owner-only tell now has a phone route, since a phone has no keyboard for `pedophilerep`. Five taps with one finger inside the bottom-right 64px corner within three seconds fire the same toggle as the typed code, and both routes now share one `toggleTell()` (persisting `STORAGE.tell` instead of a second hard-coded key). The gesture is matched on document `pointerdown` viewport coordinates rather than an invisible overlay, so it never swallows a tap meant for a real button; only primary touch pointers count, a tap outside the corner clears the streak, and the window slides so old taps expire instead of accumulating across screens. `docs/HANDOFF.md` §3c documents the touch route.
* **Firm-Farewell** (Tag: `Firm-Farewell`) — Every way out of a game now asks first, so a round cannot end by accident. The Pass & Play `QUIT GAME` buttons on the reveal and both voting screens used to drop straight back to setup; they now route through one shared `confirmQuitGame()` ("Quit this game?" → `Keep playing` / `Quit game`), and `leaveOnlineRoom()` spells out the consequences: "Leave the room?" with `Stay` / `Leave room`, or "Close the room?" for a host, with guest/host-specific warning text. `showConfirmModal(title, message, onConfirm, {confirmLabel, cancelLabel})` gained the label options backward-compatibly, marks itself `role="dialog" aria-modal="true"` and focuses Cancel, so a held Enter or a double tap stays in the game rather than confirming.
* **Empty-Chair** (Tag: `Empty-Chair`) — The host can now clear a dead phone out of an online round. `HostRoom.kick` is no longer lobby-only: mid-game it accepts a seat that is offline or *silent* (>20s without a ping, which catches the drops PeerJS never reports), while a live player can still only be booted from the lobby. Removal prunes `turnOrder` and re-runs `maybeStartDiscussion`/`maybeResolveVotes`, so the ready check or the next ballot finishes immediately instead of at the 120s sweep; `publicState` exposes `silent`, the reveal/discussion/vote/results screens show a host-only "NOT AT THE TABLE" card for those seats, and a seat retired by the sweep re-arms on its next message so a returning phone cannot be removed by mistake.
* **Kept-Seat** (Tag: `Kept-Seat`) — Fixes "if one disconnects, they can't join back". Rejoining used to depend on the host noticing the dead link, which PeerJS often never reports, so every rejoin was answered `in-progress` ("That game has already started."). Each guest seat now carries a secret key issued in `welcome` and stored per device as `fti-seat`, and `HostRoom.seatFor`/`adoptSeat` reclaim the seat by name + key mid-game, even while the old connection still looks open; a live player's seat still cannot be taken without the key. Guests also ping every 5s, and `sweepSeats` retires a silent seat after two minutes so a missing ballot cannot stall the round.
* **Steady-Seat** (Tag: `Steady-Seat`) — Resilience, memory and polish pass. Online seats survive drops: disconnected guests keep their row, `GuestClient` retries with backoff and `hello { resume: true }` re-adopts the offline seat mid-game (same role, same phase, even after a reload), while a connected player with that name still gets `name-taken`; the host can remove players from the lobby, a deliberate leave frees the seat, and a deliberate host close broadcasts `{type:'closed'}` so guests land on an `online_closed` screen with the last roster and a rejoin option. Online rooms moved behind `loadOnline()` with pure helpers in `main/online-shared.js` (main bundle 324 kB → 227 kB, online 110 kB and QR 21 kB loaded on demand), the lobby renders a join QR from the vendored `main/vendor/qr.mjs`, roster/scores/preferences/session stats persist under `fti-*` keys, word pairs can be flagged as "too similar" (skipped by `getWordSelection`'s sixth `bannedPairs` argument), the reveal card is keyboard-operable, focus rings and reduced-motion styles were added, and mute plus a speaker-change chime landed in `audio.js`.
* **Silent-Keystroke** (Tag: `Silent-Keystroke`) — The owner-only tell marker is now cheat-code gated: nothing is drawn on a fresh device until the typed code `pedophilerep` is entered outside a text field, which arms the background-matched 1px corner pixel and the faint dots after known imposter names (persisted in `localStorage` as `fti-tell`, switched off by typing the code again). Typing inside an input, textarea, select or contenteditable is ignored, and modified keystrokes reset the buffer.
* **Whisper-Signal** (Tag: `Whisper-Signal`) — Online rooms on top of Pass & Play: host-authoritative PeerJS lobbies with create/join by code or link, lobby sync, private per-device roles, reveal → ready → discussion → vote → results flow, Mr. White online guess phase, Classic single-ballot resolution, and Undercover parity across all three modes. Adds the hidden owner-only tell (a single background-matched pixel in the bottom-right corner plus faint dots after known imposter names) and vendors a self-contained `peerjs.mjs` so the static Vercel deploy needs no bundler.
* **Shadow-Infiltrator** (Tag: `Shadow-Infiltrator`) — Faithful, zero-dependency Pass & Play clone of `findtheimposter.com/game`: Classic Imposter and Undercover game modes; 45 curated categories with hundreds of word pairs; synthesized Web Audio API sound effects; deterministic SVG character avatars; 3D card-flip reveal phase; customizable discussion timer with speaking turn spotlight; pass-the-device secret ballot voting with Guardian shield protection, tie-breaking runoffs, Mr. White guess screen, and Last Chance imposter guess; celebratory victory screen with confetti and persistent scoreboard.
* **Imperial-Dominion** (Tag: `Imperial-Dominion`) — Studio-grade 9 Kings gameplay visuals and tactile HUD overhaul powered by specialized gamedev skills (`deckbuilder-ui`, `game-juice`, `game-feel`, `pixel-art-gamedev`, `create-game-assets`): authentic top HUD with gold currency (`✦ 25 +5`), breaches (`0 / 3`), left-side runic spell medallions, and milestone timeline track (`YEAR 1`).
* **Verdant-Elegance** (Tag: `Verdant-Elegance`) — Studio-grade visual overhaul of 9 Kings procedural canvas environment matching authentic Steam art: hand-chiseled rounded cobblestone wall with mortar courses and 3D fortress crenellations; multi-layered conifer spruce forest with drooping scalloped needle tiers.
* **Synchronized-Territory** (Tag: `Synchronized-Territory`) — Synchronized world camera transform locking 3x3 and 4x4 meadow grids directly to the procedural grass pasture.
* **Sapphire-Territory** (Tag: `Sapphire-Territory`) — Expandable 9 Kings territory grid system flat on the procedural meadow: starts as authentic 3x3 (9 diamond plots) and expands to 4x4 (16 diamond plots) with smooth golden border shimmer animation.
